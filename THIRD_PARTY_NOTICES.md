# Third-party notices

The `engine` directory contains a modified Snes9x 2005 Libretro core from the Libretro project, revision `a79dfe9047e7fec58808aefe48ad2bf499c7af11`.

Its existing [copyright and license notices](engine/copyright) cover Snes9x, the original authors and research contributors, the NDSSFC/BAGSFC/CATSFC ports, and the Libretro integration. Component headers retain their notices. These licenses include terms that differ between components; this project's new code does not replace them.

Source: https://github.com/libretro/snes9x2005

The launcher architecture was informed by the user's local Aladdin, Splatterhouse 3 and Indiana Jones co-op projects. Game graphics, sound and gameplay are read from the user's original ROM. No game ROM is part of the source deliverable.
